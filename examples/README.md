# Examples

Scripts that demonstrate the "Plausible but wrong" claims in each chapter. Run with `elixir examples/<file>.exs`.

Chapter 9 macros need compiling first: `elixirc examples/09_macros.ex`, then `elixir examples/09_macros_double_eval.exs`. Chapter 11 scripts are ExUnit suites in which some tests fail on purpose, to show the problem.
